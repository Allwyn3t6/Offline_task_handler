# Lyrics to Song (Colab)

`lyrics_to_song.ipynb` turns lyrics and a style description into a full song with vocals using
[ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5) on a free Colab T4 GPU.

Open it in Colab (File > Upload notebook, or via GitHub), set the runtime to T4 GPU, then run all cells.
`build_notebook.py` regenerates the notebook.
